    Help
    
    
    Tools
    
    
    Left mouse uses the current tool. Right-drag orbits, middle-drag pans, wheel zooms (or pick the Orbit tool to orbit with the left button).
    
    
    
      
    AAdd: click or drag to place voxels on the face under the mouse
    
      
    EErase: click or drag to remove voxels
    
      
    PPaint: recolour existing voxels
    
      
    IEyedropper: pick the colour of a voxel
    
      
    BBox fill: drag a rectangle on a face; the Extrude field sets how far it sticks out
    
      
    OOrbit tool
    
      
    MMirror X on/off (edits are repeated on the other side)
    
      
    [ ]Slice one layer down / up
    
      
    Ctrl+ZUndo (at least 100 steps; running a recipe is one step)
    
      
    Ctrl+Y / Ctrl+Shift+ZRedo
    
      
    Ctrl+SDownload .vox
    
      
    Ctrl+EnterRun the recipe (inside the recipe box)
    
      
    EscCancel a box drag
    
    
    
    
    The Slice slider hides everything above the chosen layer (y) so you can edit inner layers. The page saves your model and recipe in this browser automatically; New clears that.
    
    
    Recipe helpers
    
    
    model(w, h, d, scale)                 start a model (scale = metres per voxel)
box(x, y, z, w, h, d, "colour")
hollow_box(x, y, z, w, h, d, "colour", wall = 1)
cylinder(x, y, z, radius, length, "colour", axis = "y")
line(x1, y1, z1, x2, y2, z2, "colour")
remove(x, y, z, w, h, d)              cut a hole
paint(x, y, z, w, h, d, "colour")     recolour existing voxels only
mirror_x()                            copy the left half onto the right
    
    
    Axes: x = right, y = up, z = toward the viewer. Colour names come from palette.json. Loops and variables are normal JavaScript.
